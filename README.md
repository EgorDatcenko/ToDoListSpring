REST API для управления задачами (To-Do List)

Простое веб-приложение (REST API), которое позволяет создавать, получать и (в будущем) управлять задачами. У каждой задачи есть:

title (Название) - обязательно
description (Описание) - опционально
dueDate (Срок выполнения) - обязательно

Технологии, которые я здесь использую:
Java 17,
Spring Boot 3,
Spring Web,
Spring Data JPA,
Hibernate,
PostgreSQL,
Maven,
Lombok

Цель - знакомство с интеграционными тестами и с аннотациями @ControllerAdvice и @ExceptionHandler
